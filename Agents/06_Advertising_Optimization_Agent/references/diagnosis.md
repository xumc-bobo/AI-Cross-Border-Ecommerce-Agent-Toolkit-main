# diagnosis.md · 诊断规则（与脚本逻辑一一对应）

> **诊断顺序固定，不可跳步** —— 上层问题会掩盖下层问题。
> 每个广告组从上往下过，第一个命中的层级决定本轮动作。

```text
第 0 层  数据充分性（曝光 < 1,000 → INFO，本轮不动，攒数据）
第 1 层  无花费（→ INFO）
第 2 层  CTR < 2%（→ 素材问题，回流 04 —— 不在广告端解决素材问题）
第 3 层  点击 ≥ 30 且零订单（→ 落地页/价格问题，回流 03；广告端只降出价止血）
第 4 层  ROAS 分级（对照盈亏线与目标，见下表）
```

---

## ROAS 分级表

设 盈亏线 ROAS = `BE`，目标 ROAS = `T`（= 1 ÷ 目标 ACoS）：

| 条件 | 级别 | 核心动作 |
|---|---|---|
| ROAS < 0.5 × BE | **P0 止血** | 预算降至最低档 + 出价降至可承受 CPC 以下；**❗ 不暂停** |
| 0.5 × BE ≤ ROAS < BE | **P1 改善** | 出价降至可承受 CPC 以下，**预算不动**；CVR<1% 则回流 03/07 |
| BE ≤ ROAS < T | **P1 维持** | 预算与出价都不动，改善转化率是唯一杠杆 |
| ROAS ≥ T | **P2 放量** | 预算 +20~30%（一次一档），观察 3 天 |

> 为什么以 **0.5 × BE** 作为 P0 线：ROAS 连盈亏线一半都不到，
> 说明不是"贵了"而是"全错"，继续按正常节奏优化是在钝刀割肉。

## 三条底层认知（每条都有案例数据背书）

**① 基准线与盈亏线是两回事。**
某广告组可以 CTR 4.4%、CVR 1.44%、加购率 11.2% 全部达标，
ROAS 2.73 仍低于盈亏线 2.82 —— 因为 CPC 是别人的两倍。
**漏斗健康 ≠ 赚钱。**

**② 修 CTR 可能扩大亏损。**
CTR 1.4% → 3.0%（转化率 0.44% 不变）：
净贡献 −R$235 → **−R$335**。让更多不合格流量进来 = 花更多钱。
**先问转化率能不能接住，再优化点击。**

**③ 瓶颈在转化时，放大曝光 = 放大亏损。**
转化率不变，点击 2,017 → 3,000：净贡献 −R$236 → **−R$218？不，
是 −R$353**。曝光换不来钱，只换来账单。

## 本轮明确不动（iterate 纪律）

每次诊断的输出**必须包含**「本轮明确不动」清单：

| 本轮 ROAS 状态 | 明确不动 |
|---|---|
| 亏损组（P0/P1 改善） | listing 文案、素材 —— 只动广告端出价/预算 |
| 盈亏线上（P1 维持 / P2） | 预算、出价结构 —— 只优化转化率 |

一次只改一个病因；复测指标 = 被改环节能控制的那个（广告动作看 ROAS，
文案动作看误解型差评占比），**不看总销量**。
